Qué es esto

Paleta, tipografía y componentes base compartidos entre los portales ambientales de lemeit.ar (meteorología, aire, agua) y profe.lemeit.ar, de donde sale la paleta original. Un solo <link> y <script> lo traen a cualquier sitio: 

<link rel="stylesheet" href="https://design.lemeit.ar/lemeit-theme.css">
...
<script src="https://design.lemeit.ar/lemeit-common.js"></script>
<script>
  LemeitCommon.initTheme();
  LemeitCommon.initSwitcher("emas"); // "emas" | "aq" | "wq" | "profe"
  LemeitCommon.renderFooter(document.getElementById("lm-footer"), { version: "v1.0 — 2026-08-22" });
</script>
